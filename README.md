# IndustrialReforged

An industrial tech mod for **Minecraft 1.21.1 / NeoForge**, in the spirit of **IndustrialCraft 2**:
energy from 1 FE/t up to 1 GFE/t, machines with upgrades, cables and pipes, multiblock reactors,
crops and more.

Optional integrations: Applied Energistics 2 (ME machines), Botania, Cable Facades, Applied Flux,
JEI and KubeJS (see [docs/kubejs.md](docs/kubejs.md)). The mod runs without any of them.

## Building

Java 21 is required.

```sh
./gradlew build    # build/libs/industrialreforged-<version>.jar
```
